## US-1. 로그인 세션 준비

**우선순위**: Must
**관련 요구사항**: FR-1.1, FR-1.2, FR-1.3, NFR-1.1, AC-8

As a 어노테이터,
I want 도구 전용 Chrome 창에서 내가 직접 LabelOn에 로그인하고 그 세션이 유지되기를,
So that 비밀번호를 도구에 맡기지 않고도 매일 다시 로그인하지 않을 수 있다.

**인수 기준**
- Given 도구를 처음 실행했고 저장된 세션이 없다, When 검토 화면을 열면, Then 도구 전용 Chrome 창에 LabelOn 로그인 페이지가 뜨고 검토 화면에 "로그인을 완료해 주세요" 안내가 표시된다.
- Given 로그인 페이지가 떠 있다, When 내가 직접 로그인을 마치고 프로젝트 홈이 뜨면, Then 검토 화면 상태가 "준비됨"으로 바뀌고 "다음 건 가져오기" 버튼이 활성화된다.
- Given 어제 로그인한 세션이 프로필에 남아 있다, When 오늘 도구를 실행하면, Then 로그인 페이지 없이 바로 "준비됨" 상태가 된다.
- Given 도구 설치 폴더와 프로필 폴더를 검색한다, When 파일 내용을 확인하면, Then LabelOn 비밀번호와 Anthropic API 키가 어떤 파일에도 없다.

## US-2. 다음 건 가져오기

**우선순위**: Must
**관련 요구사항**: FR-2.1, FR-2.2, FR-2.3, FR-2.4, FR-5.5, NFR-3.1, NFR-4.1, AC-1

As a 어노테이터,
I want 버튼 하나로 다음 작업 건을 가져와 분석이 끝날 때까지 진행 상태를 보기를,
So that LabelOn 화면과 모델 사이를 오가지 않고 검토에만 집중할 수 있다.

**인수 기준**
- Given 상태가 "준비됨"이고 할당된 건이 없다, When "다음 건 가져오기"를 누르면, Then 도구가 데이터셋 688 작업 화면을 열고 상태가 "가져오는 중 → 1단계 판정 중 → (필요 시) 2단계 수정 중 → 검토 대기" 순으로 바뀐다.
- Given 가져오기를 시작했다, When 3분이 지나기 전에, Then 이미지, 메타데이터, 연관 QA, 초안, 판정 결과가 검토 화면에 모두 표시된다.
- Given 한 건이 이미 검토 대기 상태다, When 화면을 보면, Then "다음 건 가져오기" 버튼은 비활성화되어 동시에 2건이 할당되지 않는다.
- Given 데이터셋에 남은 건이 없다, When "다음 건 가져오기"를 누르면, Then "가져올 작업이 없습니다"와 함께 LabelOn이 보여 준 화면 종류(프로젝트 홈 등)가 표시된다.
- Given 모델 호출이 2회 재시도 후에도 실패했다, When 결과를 보면, Then 실패 사유가 표시되고 초안 원본이 그대로 검토 대기 상태로 열려 직접 검토·제출할 수 있다.

## US-3. 판정 결과와 근거 확인

**우선순위**: Must
**관련 요구사항**: FR-3.1, FR-3.3, FR-4.1, FR-4.2, domain-rules R1~R3, AC-2, AC-3, AC-4

As a 어노테이터,
I want 팩트별 참/거짓과 근거, 정합성 점수, Instruction 불일치 경고, 불가 후보 표시를 한눈에 보기를,
So that 이미지를 처음부터 훑지 않고 의심스러운 부분부터 확인할 수 있다.

**인수 기준**
- Given 판정이 끝났다, When Facts 영역을 보면, Then 5개 문장 각각에 "참 / 거짓 / 판단불가" 표시와 한 줄 근거(이미지의 어느 부분 때문인지)가 붙어 있다.
- Given 판정이 끝났다, When 상단 요약을 보면, Then 정합성 점수(0~100)와 Scene, CoT 1~3, 대화 각 턴의 정합성 판정이 표시된다.
- Given 초안의 task 문구가 archetype 템플릿과 다르거나 persona가 데이터셋 페르소나와 다르다, When 판정이 끝나면, Then Instruction 영역에 경고 배지와 "템플릿과 다른 부분" 설명이 표시되고, Instruction 값 자체는 초안 그대로 남아 있다.
- Given 정합성 점수가 설정 임계값(기본 40) 이하다, When 판정이 끝나면, Then 화면 상단에 "불가 후보" 경고와 근거(이미지에 없는 사물·장면 목록), 제안 불가 사유 문구가 표시된다.
- Given 정합성 점수가 임계값보다 높다, When 판정이 끝나면, Then 불가 후보 경고는 표시되지 않는다.

## US-4. 수정안 편집

**우선순위**: Must
**관련 요구사항**: FR-3.2, FR-3.4, FR-3.5, FR-5.2, FR-5.3, FR-5.4(되돌리기), NFR-5.2, NFR-5.3

As a 어노테이터,
I want 초안과 모델 수정안의 차이를 문장 단위로 보고 모든 필드를 직접 고치거나 초안으로 되돌리기를,
So that 모델 수정을 그대로 믿지 않고 내 판단으로 최종 내용을 확정할 수 있다.

**인수 기준**
- Given 2단계 수정이 수행되었다, When Scene, Facts, CoT, 대화 영역을 보면, Then 필드별로 초안과 수정안의 추가·삭제·변경이 서로 다른 색으로 문장 단위 표시된다.
- Given 1단계에서 수정 불필요로 판정되었다, When 화면을 보면, Then "수정 없음" 표시와 함께 초안이 그대로 편집 영역에 들어 있고 diff는 비어 있다.
- Given 검토 대기 상태다, When 수정안의 아무 텍스트 필드를 클릭해 내용을 바꾸면, Then 바뀐 값이 유지되고 diff가 초안 대비로 즉시 갱신된다.
- Given 내가 여러 필드를 편집했다, When "초안 원본으로 되돌리기"를 누르면, Then 모든 필드가 서버 초안 값으로 돌아간다.
- Given 초안 대화가 3턴이다, When 수정안을 보면, Then 4~6턴은 비어 있고 모델이 새 턴을 추가하지 않았다.
- Given 수정안이 표시되었다, When 대화 assistant 문장을 읽으면, Then 초안의 말투(아이에게 말하는 반말)와 finalAnswer.context 값이 유지되어 있다.

## US-5. 승인·제출

**우선순위**: Must
**관련 요구사항**: FR-6.1, FR-6.2, FR-6.3, FR-6.4, NFR-4.3, AC-5, AC-6

As a 어노테이터,
I want 내가 확정한 내용을 승인 버튼 한 번으로 LabelOn에 제출하고 결과를 확인하기를,
So that 제출은 항상 내 결정으로만 일어나고 성공 여부를 바로 알 수 있다.

**인수 기준**
- Given 검토 대기 상태다, When 승인 버튼을 누르기 전까지, Then LabelOn으로 향하는 제출 요청은 한 건도 발생하지 않는다.
- Given 내용을 확정했다, When "승인·제출"을 누르면, Then 화면의 최종 값으로 제출 본문이 만들어지고(facts는 JSON 배열 문자열, finalAnswer는 초안과 같은 구조의 JSON 문자열) LabelOn에 1회 제출된다.
- Given 제출이 성공했다, When 응답이 오면, Then "제출 완료"와 LabelOn 응답 메시지가 표시되고, 이력에 제출 본문과 응답이 저장되며, 상태가 "준비됨"으로 돌아가 "다음 건 가져오기"가 활성화된다.
- Given 제출이 실패했다(네트워크, 서버 오류, 세션 만료), When 응답이 오면, Then 실패 사유가 표시되고 "재시도"와 "취소" 중 선택할 수 있으며 편집 내용은 사라지지 않는다.
- Given 제출을 마쳤다, When LabelOn 작업내역 페이지를 보면, Then 해당 건의 작업량이 1 증가해 있다.

## US-6. 불가 제출

**우선순위**: Must
**관련 요구사항**: FR-4.3, AC-7

As a 어노테이터,
I want 이미지와 초안이 전혀 다른 건을 사유와 함께 불가로 제출하기를,
So that 억지로 수정해 반려되는 대신 규정대로 처리할 수 있다.

**인수 기준**
- Given 검토 대기 상태다, When "불가 제출"을 누르면, Then 불가 사유 입력란이 열리고, 불가 후보 건이면 모델이 제안한 사유가 미리 채워져 있다.
- Given 사유 입력란이 비어 있다, When 확인을 누르면, Then "불가 사유를 입력하세요" 안내가 뜨고 제출되지 않는다.
- Given 사유를 입력했다, When 확인을 누르면, Then jobStatus AK04와 사유(impossibleMsg)로 1회 제출되고 결과가 표시된다.
- Given 불가 후보가 아닌 건이다, When "불가 제출"을 누르면, Then 동일하게 사유 입력 후 제출할 수 있다(사람 판단 우선).

## US-7. 건 반환과 제한시간 대응

**우선순위**: Must
**관련 요구사항**: FR-5.4(건너뛰기), FR-8.1, FR-8.2, NFR-4.2

As a 어노테이터,
I want 남은 제한시간을 항상 보고, 처리하기 곤란한 건은 반환하고, 시간이 만료되면 상황을 알기를,
So that 60분 제한 때문에 건을 잃거나 잘못 제출하는 일을 피할 수 있다.

**인수 기준**
- Given 건을 가져왔다, When 검토 화면을 보면, Then 가져온 시각 기준 60분 카운트다운이 표시된다.
- Given 잔여 시간이 10분 미만이다, When 화면을 보면, Then 카운트다운이 경고 색으로 바뀌고 알림 문구가 표시된다.
- Given 검토 대기 상태다, When "이 건 건너뛰기"를 누르면, Then 확인 질문 후 현재 건이 LabelOn에 반환(reset)되고 이력에 "건너뜀"으로 기록되며 상태가 "준비됨"이 된다.
- Given 제한시간이 만료되었다, When 승인 또는 불가 제출을 시도하면, Then "제한시간이 만료되어 이 건은 반환되었습니다" 안내가 뜨고 이력에 "만료"로 기록되며 다시 가져오기를 안내한다.
- Given 도구가 비정상 종료되었다, When 다시 실행하면, Then 이력에 미완료(검토 대기 중이던) 건이 표시되고, LabelOn 만료로 자동 반환된다는 안내가 함께 표시된다.

## US-8. 이력과 비용 확인

**우선순위**: Should
**관련 요구사항**: FR-7.1, FR-7.2, FR-7.3, NFR-7.1

As a 어노테이터,
I want 처리한 건의 원본·판정·수정·제출 내용과 누적 토큰 사용량을 다시 보기를,
So that 반려가 오면 무엇을 보냈는지 확인하고 비용을 관리할 수 있다.

**인수 기준**
- Given 여러 건을 처리했다, When 이력 탭을 열면, Then 최근 순으로 건 목록(파일명, 처리 시각, 결과: 제출/불가/건너뜀/만료, 정합성 점수)이 표시된다.
- Given 이력 목록에서 한 건을 선택했다, When 상세를 열면, Then 이미지(캐시가 남아 있으면), 초안, 1단계 판정, 2단계 수정안, 내 최종 편집값, 제출 본문, LabelOn 응답, 사용 토큰이 표시된다.
- Given 이력 탭이 열려 있다, When 상단 요약을 보면, Then 오늘과 누적 처리 건수, 결과별 건수, 누적 토큰 사용량이 표시된다.
- Given 이미지 캐시 보관 일수(기본 7일)가 지났다, When 도구를 실행하면, Then 해당 이미지 파일은 삭제되고 이력의 텍스트 데이터는 유지된다.

## US-9. 설정 변경

**우선순위**: Could
**관련 요구사항**: NFR-6.1, NFR-6.2

As a 어노테이터 겸 도구 운영자,
I want 임계값, 모델 ID, 데이터셋 ID, 페르소나, 아키타입 템플릿을 설정 파일에서 바꾸기를,
So that 다른 데이터셋이나 기준 변경에 코드 수정 없이 대응할 수 있다.

**인수 기준**
- Given 설정 파일에서 임계값을 40에서 50으로 바꿨다, When 도구를 다시 실행해 건을 가져오면, Then 점수 50 이하가 불가 후보로 표시된다.
- Given 설정 파일에서 데이터셋 ID를 687로 바꿨다, When 건을 가져오면, Then 687 작업 화면이 열린다(동작 검증은 이번 범위 밖, 설정 반영만 확인).
- Given 설정 파일 문법이 잘못되었다, When 도구를 실행하면, Then 어느 항목이 잘못되었는지 알려 주고 종료한다.
