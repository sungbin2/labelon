## P-1. 어노테이터 겸 도구 운영자 (성현)

| 항목 | 내용 |
|---|---|
| 역할 | LabelOn UC-LE 데이터셋 688의 고급자 어노테이터. 자신의 PC에서 검토 도구를 직접 실행·설정한다 |
| 배경 | LabelOn에서 물고기, BBOX, 문장요약 등 여러 데이터셋을 처리한 경험이 있다. 이미지 태깅과 텍스트 검수에 익숙하며 Python 환경을 다룰 수 있다 |
| 작업 맥락 | 하루 중 일정 시간을 정해 로컬 검토 화면을 열고 1건씩 처리한다. 화면 옆에 LabelOn 작업 창이 함께 열려 있다 |
| 목표 | 1,000건 이상을 검수 반려 없이 처리하고, 건당 소요 시간을 초안을 직접 읽고 고치는 것보다 크게 줄인다 |
| 어려움 (현재) | 초안의 Facts 5개와 대화 3턴을 매번 이미지와 대조해야 한다. 아키타입 템플릿과 task 문구가 미묘하게 다른 경우를 눈으로 잡기 어렵다. 60분 제한시간 안에 3건을 끝내야 하는 압박이 있다. 어떤 건을 불가로 낼지 기준이 흔들린다 |
| 도구에 기대하는 것 | 틀린 팩트와 근거를 먼저 보여 주고, 수정안은 최소 변경으로 문체를 유지하고, 제출은 반드시 본인이 누른다. 무엇을 보냈는지 나중에 다시 볼 수 있어야 한다 |
| 성공 지표 | 검수 반려율 5% 미만 유지. 건당 검토 시간 5분 이내. 제한시간 만료로 잃는 건 0 |
| 기술 수준 | 중상. 설정 파일 편집과 명령 실행이 가능하지만, 매일 쓰는 도구는 클릭만으로 동작해야 한다 |

### 관련 스토리
- US-1 로그인 세션 준비
- US-2 다음 건 가져오기
- US-3 판정 결과와 근거 확인
- US-4 수정안 편집
- US-5 승인·제출
- US-6 불가 제출
- US-7 건 반환과 제한시간 대응
- US-8 이력과 비용 확인
- US-9 설정 변경

- **LabelOn 검수자**: 제출물을 승인·반려한다. 도구를 직접 쓰지 않지만, 스토리의 인수 기준(팩트 정확성, 문체 유지, 불가 사유 명확성)은 이 사람의 판단 기준을 대리한다.
