# Domain Rules: UC-LE 초안 검토 기준

출처: 사용자 제공 (2026-09-23). 자동화 도구가 초안을 검토할 때 적용하는 고정 규칙.

## 1. Instruction 구조

Instruction은 세 항목으로 구성되며 값이 정해져 있다.

- **archetype**: 아래 6종 중 하나
- **persona**: 데이터셋별로 정해진 사용자 유형 (예: 688 데이터셋은 "장난기가 많은 어린아이")
- **task**: archetype별 고정 템플릿. 템플릿의 `(Persona)` 자리에 persona 문구가 들어간다

## 2. Archetype별 Task 템플릿

| Archetype | Task 템플릿 |
|---|---|
| 일상지원 | (Persona) 이 주변에서 가려는 곳과 필요한 것을 찾아갈 수 있도록 주변 시설과 길이 어떻게 이어져 있는지 확인하고, 어느 쪽으로 가야 하는지와 걸리는 것을 우선 안내하세요. (2026-09-30 변경. 옛 문장 "(Persona) 이 공간에서 필요한 것을 찾을 수 있도록 주변 시설과 물건이 어떻게 놓여 있는지 확인하고, 무엇이 어느 쪽에 있는지 우선 안내하세요." 초안도 일치로 인정) |
| 보행안전 | (Persona) 안전하게 이동할 수 있도록 진행 방향의 보행환경을 확인하고, 이동 경로의 장애물과 위험요소를 우선 안내하세요. |
| 쇼핑 | (Persona) 찾는 물건에 닿을 수 있도록 물건이 어디에 어떻게 놓여 있는지 확인하고, 손을 뻗을 방향과 걸리는 것을 우선 안내하세요. |
| 음식 | (Persona) 음식을 스스로 다룰 수 있도록 음식과 관련된 것이 어디에 있는지 확인하고, 손이 닿는 방향과 조심할 것을 우선 안내하세요. |
| 실내탐색 | (Persona) 실내를 스스로 다닐 수 있도록 공간의 구조와 가구 배치를 확인하고, 지나갈 길과 부딪힐 만한 것을 우선 안내하세요. |
| 가전조작 | (Persona) 기기를 다룰 수 있도록 가전이 어디에 있고 어느 면이 앞면인지, 보이는 조작 단서(손잡이·표시등·틈·문)가 무엇인지 짚고, 어느 쪽에서 무엇을 만지면 되는지 우선 안내하세요. |

검증 예시 (688 데이터셋, 실제 초안):
- archetype "음식", persona "장난기가 많은 어린아이"
- task "장난기가 많은 어린아이가 음식을 스스로 다룰 수 있도록 음식과 관련된 것이 어디에 있는지 확인하고, 손이 닿는 방향과 조심할 것을 우선 안내하세요."
- 템플릿의 `(Persona)`가 "장난기가 많은 어린아이가"로 치환된 형태와 일치함

## 3. 검토 규칙

### R1. 페르소나-태스크 정합성
- task 문구가 archetype 템플릿과 일치하는지 확인한다 (persona 치환 부분 제외).
- persona와 task가 완전히 다르면(예: 시각장애인 페르소나에 어린이용 문구, 또는 archetype과 무관한 task) 검토 대상이다.
- 이 경우 CoT 3단계와 최종 답변 QA가 올바른 persona와 task에 맞게 생성되어 있어야 한다. 맞지 않으면 수정한다.

### R2. 이미지 정합성
- Scene, Facts, CoT, QA 중 이미지와 전혀 다른 내용이 있으면 수정한다.
- 이미지와 초안 전체가 전혀 다르면(장면 자체가 다른 경우) 불가로 제출한다. (사전 확정 사항)

### R3. 팩트 검증
- Facts 각 문장을 이미지와 대조해 참/거짓을 판정한다.
- 거짓인 팩트는 이미지에 근거한 참인 문장으로 수정한다.
- Scene, CoT, QA가 수정된 팩트와 모순되지 않게 정리한다.

## 4. 미확정 사항 (질문 파일 참조)
- 불가 판정의 정량 기준 (Q3)
- 모델이 자동 수정할 수 있는 범위와 사람 확인의 경계 (Q4)
- 비어 있는 대화 턴 처리 (Q5)
