## 새로 반영할 항목

### N1. 오탈자·맞춤법 (11쪽, 오류 예시 1)
- "오탈자 및 맞춤법: 모든 영역 확인 → 텍스트 수정". 예: QA 의 "베런다" → "베란다"
- 현재 도구: 사진 정합성만 판정하므로 오탈자만 있는 초안은 수정 필요로 잡히지 않음

### N2. 주관적 추측 금지 (11쪽)
- "주관적인 추측으로 작성 금지". 현재 revise 규칙 7(추측 금지)에는 있으나 judge 는 추측 문장을 표시하지 않음

### N3. 숫자 표기 (오류 예시 3)
- 이미지에 적힌 숫자는 **숫자 그대로** 적는다. "열세 번과 열두 번이 적힌 안내판" → "13번과 12번"
- 현재 도구: 규칙 없음

### N4. 물체 오인식 전파 (불가 예시 1)
- '뻥이요' 과자를 '뻥이요' 빵으로 인식 → Facts·CoT·QA 전체가 잘못된 물체 위에 세워짐 → **불가**
- 현재 도구: 거짓 팩트 3개 이상 또는 불일치 필드 4개 이상이면 불가 후보(수정량 과다)로 간접 포착. 팩트 1개만 틀리고 QA 만 오염된 경우 놓칠 수 있음

### N5. 페르소나에 맞지 않는 안내 (불가 예시 2)
- 시각장애 성인에게 "박스 더미가 **보이면** 멈추고 발밑을 확인하세요" 처럼 시각적 확인을 요구 → **불가**
- 현재 도구: persona_task_fit 로 수정 대상이 될 수는 있으나 불가 사유는 아님

### N6. Facts 오해로 멀티턴이 꼬임 (불가 예시 3)
- "자판기와 팝콘 판매대 사이 바닥에 타일 통로가 이어져 있다"(기계 사이 틈을 통로로 오해) → CoT·QA 가 그 위에서 전개 → **불가**. "일반적인 통로는 복도와 같은 형태"
- N4 와 같은 유형: 핵심 팩트 오류가 CoT·QA 로 전파

### N7. 위험 행위 권고 (불가 예시 4)
- 횡단보도가 없는 도로에서 "차가 없는지 확인해서 천천히 건너가" → 무단횡단 권고 → **불가**. "도로 위를 건너지 않도록 안내해야 함"
- 현재 도구: 규칙 없음

### N8. 아키타입이 이미지 환경과 맞지 않음 (불가 예시 5·6)
- 실외 도로 사진에 일상지원("이 공간에서 필요한 것을 찾을 수 있도록") → 불가. 실외 도로에 실내탐색 → 불가. 실외 인도에 음식 → 불가
- 현재 도구(사이클 3): 아키타입이 QA 내용과 다르면 **정정**(템플릿 치환)을 제안. 사이클 3 근거였던 스크린샷 1 은 "QA 는 이미지와 맞는데 라벨만 틀린" 경우(음식 → 쇼핑)였고, 가이드 불가 예시 5·6 은 **아키타입이 이미지 환경 자체와 충돌**하는 경우. 두 경우를 구분해야 함
