# Cycle 11 Requirements: AI 끄기(수동 검토 모드) · 가이드 체크리스트

작성일: 2026-10-04. 깊이: Minimal. 실행: Code Generation → Build and Test.

## 1. Intent
| 항목 | 내용 |
|---|---|
| User Request | "AI 기능을 끄고 가이드 양식에 따라 수정해야할 사항만 수정할수 있는 기능버튼이 추가되었으면 합니다." |
| 해석 | 헤더에 **AI 판정 on/off 토글**. 꺼져 있으면 건을 가져와도 모델(판정·수정)을 호출하지 않고 서버 초안을 그대로 검토 대기로 올린다. 대신 가이드 검수 양식을 **체크리스트**로 보여 주고, 모델 없이 되는 규칙 검사(템플릿 일치·전화번호·두 방향 표현)만 경고로 표시한다. 사람은 필요한 항목만 고쳐 승인·불가 제출 |
| Complexity | Low-Moderate |

## 2. 기능 요구사항
### FR-C11-1. AI 토글
- 헤더 토글 "AI 판정"(기본 켜짐). 상태는 `data/ui-state.json` 에 저장되어 재시작 후 유지. 검토 중(REVIEW·BUSY)에는 변경 불가(다음 건부터 적용)
- `PUT /settings/ai {enabled}`, 상태 페이로드에 `ai_enabled`

### FR-C11-2. 수동 모드 가져오기
- AI 꺼짐: 가져오기 → 파싱 → 이미지 캐시·이미지 탭 → **판정·수정 생략** → 바로 검토 대기. 판정 결과 없음, 수정안 없음(최종안 = 초안). 규칙 검사 경고: Instruction 템플릿 불일치, 전화번호, 두 방향 결합 표현
- "다시 판독(Alt+S)"은 수동 모드에서도 **AI 로 실행**된다(사용자가 명시적으로 요청한 경우). 버튼 툴팁에 안내
- 기록(history)에는 judge 없음으로 저장. 건수 집계는 동일

### FR-C11-3. 가이드 체크리스트 패널
- 판정 패널 자리에 가이드 검수 양식 체크리스트(브라우저 내 체크 상태, 건이 바뀌면 초기화): 이미지↔Facts 대조, Task↔QA 방향, 아키타입 적합(환경·가구 포함), CoT 단계 역할, QA↔CoT3, 턴 범위(사진 밖 인물·상황), 오탈자·맞춤법, 숫자 표기, 두 방향 표현, 전화번호, 도움 요청은 보이는 사람에게만, 어린이 말투, 불가 기준(오인식 전파·시각적 확인 요구·위험 권고·환경 충돌·조작부 미가시)
- AI 켜짐일 때도 판정 결과 아래에 접힌 상태로 제공(선택)

## 3. 인수 기준
- AC-C11-1 `PUT /settings/ai {enabled:false}` 후 가져오기를 하면 모델 호출 0회, 상태 REVIEW, judge None, final == draft, 규칙 경고 포함
- AC-C11-2 재시작 후 ui-state 로 ai_enabled 복원
- AC-C11-3 수동 모드에서 다시 판독 → judge 생성(모델 호출)
- AC-C11-4 기존 121개 테스트 유지
