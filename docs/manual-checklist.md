# 수동 검증 체크리스트 (실브라우저 · 실모델)

자동 테스트가 대신할 수 없는 항목입니다. 각 항목은 사용자가 화면을 보면서 수행하고, 결과를 기록합니다.
주의: 3~6 은 실제 LabelOn 에 제출·반환이 발생합니다. 검수자에게 보내도 되는 건으로 진행하세요.

## 0. 준비
- [ ] `run.bat` 실행 → 검토 화면(127.0.0.1:8765)과 Chrome 창이 열린다
- [ ] Chrome 창에서 LabelOn 로그인 → 검토 화면 배지가 "준비됨"으로 바뀐다 (US-1)
- [ ] `run.bat` 을 종료 후 다시 실행 → 로그인 없이 바로 "준비됨" (세션 보존)
- [ ] `.profile/`, `data/`, `logs/` 어디에도 비밀번호·API 키가 없다 (AC-8)

## 1. 컨텍스트 벤치 (NFR C-3)
- [ ] `.venv\Scripts\python scripts\bench_cli_context.py` 실행 → 3개 프로필의 context_total 기록
- [ ] 최소 조합을 `config.yaml` `cli.flags_profile` 에 반영. `minimal` 이 오류를 내면 `system_prompt` 사용
- 기록: basic = ____ / system_prompt = ____ / minimal = ____ tokens

## 2. 가져오기·판정 (US-2, US-3)
- [ ] "다음 건 가져오기" → 상태가 가져오는 중 → 판정 중 → (수정 중) → 검토 대기로 바뀐다
- [ ] 3분 이내에 이미지·메타·연관 QA·초안·판정이 표시된다 (AC-1). 소요: ____초
- [ ] Facts 5개에 TRUE/FALSE/UNKNOWN 배지와 근거가 붙어 있다 (AC-2)
- [ ] 정합성 점수와 필드 정합 표가 표시된다. Instruction 이 템플릿과 일치하면 "템플릿 일치" 배지
- [ ] 카운트다운이 LabelOn 작업 화면의 제한시간과 1분 이내로 일치한다 (시간대 보정 확인)
- [ ] 이미지 클릭 → 확대 창, 휠로 줌

## 3. 편집·승인 제출 (US-4, US-5) — 실제 제출 1건
- [ ] 수정안이 있으면 diff 가 삭제(빨강)/추가(초록)로 표시된다
- [ ] 텍스트를 고치면 "변경됨" 배지와 diff 가 갱신된다. "초안으로 되돌리기"가 동작한다
- [ ] 승인 전까지 LabelOn 화면에 변화가 없다 (AC-5). Chrome 창의 textarea 가 비어 있는지 확인
- [ ] "승인·제출" → 확인 → Chrome 창의 textarea 가 채워지고 제출·확인 모달이 자동으로 처리된다
- [ ] 검토 화면에 "제출 완료 저장되었습니다" 표시, 상태 "제출 완료"
- [ ] LabelOn 프로젝트 > 작업내역에서 688 데이터셋 작업량이 1 증가 (AC-6)
- [ ] 이력 탭에서 해당 건의 제출 payload 와 응답이 보인다

## 4. 불가 제출 (US-6) — 실제 제출 1건
- [ ] 불가 후보 건(또는 임의 건)에서 "불가 제출" → 사유 입력란에 제안 사유가 채워져 있다
- [ ] 빈 사유로 확인 → 거부 메시지
- [ ] 사유 입력 후 확인 → Chrome 창에서 "불가" 라디오·사유 입력·제출·"[작업불가]" 확인 모달이 처리된다 (AC-7)
- [ ] 결과가 "저장되었습니다" 가 아니면 이력에 실패로 기록되고 상태가 검토 대기로 돌아온다

## 5. 반환·다시 판독 (US-7)
- [ ] 검토 대기 건에서 작은 "반환" 버튼 → 확인 → 상태 "준비됨", 이력에 SKIP
- [ ] 검토 대기 건에서 "다시 판독(Alt+S)" → 판정·수정이 다시 실행되고 같은 건이 검토 대기로 돌아옴
- [ ] Chrome 창이 프로젝트 홈으로 이동하고, 다음 가져오기에서 같은 건 또는 다른 건이 정상적으로 열린다

## 6. 제한시간 (US-7)
- [ ] 잔여 10분 미만이 되면 카운트다운이 빨갛게 깜빡이고 토스트가 1회 뜬다
- [ ] 만료 후 승인 시도 → "제한시간이 만료되어 이 건은 반환되었습니다", 상태 "제한시간 만료", 이력 EXPIRED

## 7. 장애 시나리오
- [ ] Chrome 창을 사용자가 닫음 → 배너와 "브라우저 다시 열기" 버튼 → 클릭 시 재실행·로그인 유지
- [ ] 검토 대기 중 서버 종료(Ctrl+C) 후 재시작 → 이력 탭 상단에 "미완료" 배지
- [ ] `config.yaml` 에 `model_backend: fake` 로 실행 → 모델 없이 UI 흐름만 확인 가능
- [ ] `claude` 를 PATH 에서 제거하고 가져오기 → "판정 모델 호출 실패" 경고와 함께 초안 그대로 검토 대기 (BR-41)
